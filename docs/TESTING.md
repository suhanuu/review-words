# Review Words 测试清单

建议先在 Chrome / Edge 最新版测试。所有数据默认在当前浏览器本地保存。

## A. 部署与启动
1. 按 `GITHUB-PAGES.md` 部署到 GitHub Pages。
2. 打开 Pages 地址，按 F12 → Console，确认没有红色 JavaScript 错误。
3. 在 Application → Storage 检查 IndexedDB 中是否出现 `review-words-db`，对象仓库 `kv`。
4. 刷新页面，确认仍能进入学习、作文、书架、统计页面。

## B. 红宝书与旧数据迁移
1. 如果是首次使用新版本，进入学习页，确认红宝书词库可正常显示。
2. 对一个词分别点“忘了”“模糊”“很熟”，确认每次都进入下一个词。
3. 进入书架，导出 JSON 备份。
4. 刷新后检查学习记录仍存在；不要直接清除站点数据测试，以免删除唯一数据副本。

## C. 多词书隔离
1. 准备一个 UTF-8 CSV/TXT，每行格式：`apple | /ˈæpəl/ | 苹果`。
2. 书架创建新词书并导入。
3. 确认自动切换到新书，词库只显示导入词，不混入红宝书。
4. 学习几个词、收藏一个词，切回红宝书，确认两本书进度/收藏互不串用。
5. 再切回自定义词书，确认进度仍在。

## D. 薄弱词选择页与作文
1. 在学习页对一些词选择"忘了""模糊"，再收藏几个词。
2. 进入作文训练，确认卡片默认只显示 10 个已选词、标签只有"忘了 / 模糊"，仅收藏的词不出现；卡片计数形如"已选 10 / N 个词"。
3. 点"查看 / 选择"进入独立的"今日薄弱词汇"页，确认两个分组的词数与学习记录一致，顶部有 6–12 个的数量参考。
4. 逐词勾选、"全选本组 / 清空本组"、"按优先级自动选 10 个"，确认底部计数实时变化；超过 12 个变黄色警告。
5. 点"← 返回作文训练"，确认未确认的改动会先弹一次确认，取消后仍停留在选词页；再进去修改并点"确认选择"，确认卡片只显示新选的词。
6. 长词表（80 个以上）下滚动选词，确认底部确认条始终吸在视口下沿、手机上不被底部导航遮住，随时可以点"确认选择"。
7. 刷新页面确认选择仍在；清空到 0 个再刷新，确认不会被自动填回 10 个。
8. 切换到另一本词书再切回，确认两本书的选择互不串用；学习产生新薄弱词后，确认卡片提示"另有 N 个新薄弱词未选"。
9. 一个词都不选时点"生成作文"，确认自动打开选词页并给出提示；选超过 24 个时确认明确拒绝；选 13–24 个时确认生成前有一次确认提示。
10. 没有配置 AI API 时，手动粘贴英文和中文翻译，仍能正常练习。

## E. AI 生成（浏览器直连 OpenAI 兼容 API）
1. 在作文训练页展开"AI API 设置"，填写 API Base URL、API Key、模型名称，先"测试连接"再"保存 API 设置"。
2. 选 6–12 个目标词进行首次测试。
3. 生成后检查英文正文、中文翻译、目标词覆盖、文章历史，以及进度条上的目标词数。
4. 生成成功后确认本批词已移出卡片选择集，可以接着选下一批。
5. 若返回缺词、长度异常或服务错误，页面应显示失败原因且不保存该文章。
6. 确认 API Key 不会出现在导出的 JSON 备份中。

## F. 打字训练与统计
1. 载入文章，点"开始打字"进入全屏打字页，确认原文逐字着色、虚拟键盘与手指提示正常。
2. 故意输入错字，确认对应字符标红，实时速度 / 准确率 / 错误数有变化。
3. 提交后检查 WPM、准确率、差异数与结果提示。
4. 打开统计页，检查作文练习次数、平均 WPM、平均准确率和最近记录。

## G. 备份恢复（请使用测试数据）
1. 在书架导出 JSON。
2. 新增一条测试学习记录或测试词书。
3. 导入刚才备份，确认备份中同名数据键被恢复。
4. 确认文章、词书、学习记录可重新显示。
5. 重要：恢复会覆盖同名数据键，务必先备份当前数据。

## H. 边界与隐私
- 不要把 API Key 写进 `index.html`、`assets/` 或 GitHub 仓库；密钥只保存在当前浏览器本地，也不会进入 JSON 备份。
- JSON 备份包含学习记录、收藏、文章等个人数据，不要提交到公开仓库。
- IndexedDB 镜像桥接以兼容旧同步应用；localStorage 仍作为运行时缓存。不要把清除 localStorage 当作测试步骤。
- 本项目尚未做真实多浏览器端到端自动化；以上交互测试需在部署后手动完成。

## I. 本轮页面滚动与重复原文修复
1. 进入作文训练，生成一篇文章或从文章历史中点击“查看”。
2. 确认英文原文只显示一份带目标词高亮的阅读区域；下方不再出现重复的英文文本框。
3. 确认中文翻译仍显示，点击“开始打字”后仍能正确读取同一篇英文原文。
4. 点击“查看文章历史”，将窗口高度保持在常见桌面尺寸，连续向下滚动，确认能看到列表底部的历史文章。
5. 点击较靠下的一条历史记录的“查看”，确认能返回作文训练并加载对应文章。
6. 分别检查作文训练、书架、收藏、统计、词库、学习和打字练习：长内容应在对应页面或内容区域内正常查看；学习/打字练习的专用布局保持不变。
7. 在窄屏或手机尺寸重复检查文章历史，确认页面使用正常的页面纵向滚动，不出现横向溢出。
