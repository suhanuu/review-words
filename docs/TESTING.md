# Review Words 测试清单

建议先在 Chrome / Edge 最新版测试。所有数据默认在当前浏览器本地保存。

## A. 部署与启动
1. 按 `GITHUB-PAGES.md` 部署到 GitHub Pages。
2. 打开 Pages 地址，按 F12 → Console，确认没有红色 JavaScript 错误。
3. 在 Application → Storage 检查 IndexedDB 中是否出现 `review-words-db`，对象仓库 `kv`。
4. 刷新页面，确认仍能进入学习、作文、书架、统计页面。

## B. 红宝书与旧数据迁移
1. 如果是首次使用新版本，进入学习页，确认红宝书词库可正常显示。
2. 对一个词分别点“忘了”“模糊”“很熟”，确认每次都进入下一个词。
3. 进入书架，导出 JSON 备份。
4. 刷新后检查学习记录仍存在；不要直接清除站点数据测试，以免删除唯一数据副本。

## C. 多词书隔离
1. 准备一个 UTF-8 CSV/TXT，每行格式：`apple | /ˈæpəl/ | 苹果`。
2. 书架创建新词书并导入。
3. 确认自动切换到新书，词库只显示导入词，不混入红宝书。
4. 学习几个词、收藏一个词，切回红宝书，确认两本书进度/收藏互不串用。
5. 再切回自定义词书，确认进度仍在。

## D. 薄弱词池与作文
1. 在学习页对一些词选择“忘了”“模糊”，再收藏几个词。
2. 进入作文训练，检查薄弱词来源标签，确认重复词只出现一次。
3. 取消勾选一个词，确认生成时不会带上它。
4. 点击“准备今日任务”，确认只出现待生成状态，没有自动调用 AI。
5. 没有配置 Worker 时，手动粘贴英文和中文翻译，仍能正常练习。

## E. AI 生成（需要自行配置 Cloudflare Worker）
1. 按 `AI-WORKER-SETUP.md` 部署 Worker 并添加 `GEMINI_API_KEY` Secret。
2. 在作文页填写 Worker URL，选 1–3 个薄弱词进行首次测试。
3. 生成后检查英文正文、中文翻译、目标词覆盖、文章历史。
4. 若返回缺词、长度异常或服务错误，页面应显示失败原因且不保存该文章。
5. 对剩余勾选词再次生成，确认可分批练习。

## F. 打字训练与统计
1. 载入文章，选择严格模式，输入错误字符，确认不能越过错误字符；退格后可继续。
2. 选择自由模式，故意输入错字，确认可自由编辑并提交。
3. 提交后检查 WPM、准确率、差异数。
4. 打开统计页，检查作文练习次数、平均 WPM、平均准确率和最近记录。

## G. 备份恢复（请使用测试数据）
1. 在书架导出 JSON。
2. 新增一条测试学习记录或测试词书。
3. 导入刚才备份，确认备份中同名数据键被恢复。
4. 确认文章、词书、学习记录可重新显示。
5. 重要：恢复会覆盖同名数据键，务必先备份当前数据。

## H. 边界与隐私
- 不要把 `GEMINI_API_KEY` 写进 `index.html`、`assets/`、GitHub 仓库或 Worker 前端变量；只使用 Cloudflare Worker Secret。
- JSON 备份包含学习记录、收藏、文章等个人数据，不要提交到公开仓库。
- IndexedDB 镜像桥接以兼容旧同步应用；localStorage 仍作为运行时缓存。不要把清除 localStorage 当作测试步骤。
- 本项目尚未做真实多浏览器端到端自动化；以上交互测试需在部署后手动完成。

## I. 本轮页面滚动与重复原文修复
1. 进入作文训练，生成一篇文章或从文章历史中点击“查看”。
2. 确认英文原文只显示一份带目标词高亮的阅读区域；下方不再出现重复的英文文本框。
3. 确认中文翻译仍显示，点击“开始打字”后仍能正确读取同一篇英文原文。
4. 点击“查看文章历史”，将窗口高度保持在常见桌面尺寸，连续向下滚动，确认能看到列表底部的历史文章。
5. 点击较靠下的一条历史记录的“查看”，确认能返回作文训练并加载对应文章。
6. 分别检查作文训练、书架、收藏、统计、词库、学习和打字练习：长内容应在对应页面或内容区域内正常查看；学习/打字练习的专用布局保持不变。
7. 在窄屏或手机尺寸重复检查文章历史，确认页面使用正常的页面纵向滚动，不出现横向溢出。
