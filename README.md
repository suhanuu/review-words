# Review Words 使用帮助

> 本文档对应当前版本的 Review Words。项目是一个基于原生 HTML、CSS 和
> JavaScript 的英语单词学习与英文作文打字训练网站，可通过 GitHub Pages
> 发布。

## 一、项目简介

Review Words
将单词记忆、复习、薄弱词汇整理、英文文章阅读和打字训练放在同一个网站中。

当前主要功能：

-   内置考研英语红宝书词库。
-   通过"忘了、模糊、很熟"记录单词掌握程度，并安排后续复习。
-   支持单词发音、详细释义和收藏。
-   支持导入自定义 CSV / TXT 词表。
-   根据学习薄弱词汇整理作文训练词汇。
-   支持配置 OpenAI 兼容格式的 AI API 生成英文文章及中文翻译。
-   支持手动粘贴英文文章进行练习，不配置 AI 也可以使用。
-   支持文章历史查看、全选、多选和批量删除。
-   支持英文打字练习及速度、准确率等成绩记录。
-   支持导出和恢复本地数据 JSON 备份。

## 二、开始使用

### 在线使用

打开项目发布后的 GitHub Pages 网站即可使用。推荐使用最新版 Microsoft
Edge 或 Google Chrome。

### 本地使用

将项目下载并解压，使用浏览器打开项目根目录中的
`index.html`。如果浏览器或接口服务对本地文件访问有限制，建议通过 GitHub
Pages 或本地静态服务器访问。

### 页面导航

顶部导航主要包括：

| 页面 | 用途 |
| --- | --- |
| 学习 | 查看单词、评价熟悉程度并复习 |
| 作文训练 | 整理薄弱词、生成或录入文章 |
| 书架 | 管理词书及备份数据 |
| 统计 | 查看学习与作文打字相关统计 |
| 词库 | 搜索、浏览和导入单词 |
| 收藏 | 查看已收藏的单词 |

右上角可切换深浅色主题，并打开设置。

## 三、学习：背单词与间隔复习

1.  进入"学习"页面。
2.  查看当前单词、音标及学习提示。
3.  点击发音按钮可以播放单词读音；点击"详细释义"查看扩展释义。
4.  根据自己的记忆情况选择：
    -   **忘了**：表示基本没有记住，系统会较短时间后安排复习。
    -   **模糊**：表示有印象但不牢固，系统会安排再次复习。
    -   **很熟**：表示已经掌握，后续复习间隔会延长。
5.  也可以使用键盘快捷键：`J` 对应"忘了"，`K` 对应"模糊"，`L`
    对应"很熟"。如果快捷键没有响应，可直接点击页面按钮。
6.  点击星标按钮可收藏当前单词。

复习会优先安排已经到期的单词；尚未学习的单词按词书顺序继续出现。复习间隔会根据评价结果动态调整，因此不同单词下一次出现的时间可能不同。

## 四、作文训练

### 1. 选择今日薄弱词汇

进入"作文训练"页面，系统会根据当前词书的学习记录整理薄弱词汇，分为**忘记**和**模糊**两组；仅收藏的词不出现在这里，请在"我的收藏"页查看。

卡片默认按忘记优先自动选 10 个词，并且只显示已选的词。点击卡片右侧的"查看 / 编辑选择"进入独立的"今日薄弱词汇"页面：

- 两个分组分别列出该词书下所有忘记、模糊的词，可逐词勾选，也可"全选本组 / 清空本组"。
- 顶部提供数量参考：**建议每次选 6–12 个，推荐 8–10 个，最多 24 个**。目标词过多时模型容易漏词、需要重试，会明显增加 token 消耗。
- "按优先级自动选 10 个"可以一键恢复默认选择。
- 底部实时显示已选数量；少于 6 个会提示练习强度可能不足，超过 12 个会变黄色提示并在生成前再确认一次，超过 24 个会明确要求先减少。
- 只有点"确认选择"才会保存并返回；"← 返回作文训练"会丢弃本次未确认的改动。

选择按词书分别保存在当前浏览器，刷新后仍然有效；用户主动清空到 0 个不会被自动填回。学习产生的新薄弱词不会自动加入已保存的选择，卡片会提示"另有 N 个新薄弱词未选"。生成成功后，本批词会移出选择集，方便继续选下一批。

### 2. 生成英文文章

1.  先按需配置 AI API（见"AI API 配置"）。
2.  选择文章难度：大学英语四级 CET-4 或大学英语六级 CET-6。
3.  确认卡片上的目标词（建议 6–12 个）。一个也没选时，点击"生成作文"会自动打开选词页。
4.  点击"生成作文"并等待结果。
5.  成功后，页面显示英文原文、目标词高亮和中文翻译。

当前生成逻辑会检查文章是否包含所选目标词，并检查文章长度。生成失败时请根据页面提示检查
API 配置、模型能力或重新尝试。

### 3. 手动录入文章

不使用 AI 也可以练习：

1.  在英文原文输入区域粘贴自己的英文文章。
2.  如有中文译文，可填写中文翻译区域。
3.  点击"开始打字"进入练习。

手动文章不要求配置
API。请注意：只有保存到文章历史中的文章才会出现在历史列表；手动输入内容是否进入历史取决于当前页面的保存流程，重要内容建议另行留存。

## 五、文章历史与批量删除

在作文训练页面点击"查看文章历史"，可以按生成时间浏览已保存的文章。

### 查看文章

点击某条记录右侧的"查看"，即可返回作文训练页面并载入对应文章，继续阅读或开始打字练习。

### 多选与全选

1.  勾选文章左侧的复选框，可选择单篇或多篇文章。
2.  点击"全选"可选中当前历史列表中的全部文章。
3.  再次点击"全选"可取消全选。
4.  页面会显示当前选中的文章数量。

### 批量删除

1.  勾选需要删除的文章，或先点击"全选"。
2.  点击"删除选中"。
3.  在确认提示中确认删除。

**重要：删除确认后，选中的文章会从本地文章历史中移除，无法通过页面撤销。**
删除前请确认选择正确；如果文章很重要，建议先通过浏览器数据备份功能导出数据。删除文章历史不会清空单词学习记录或收藏。

## 六、英文打字练习

1.  在作文训练页面载入或生成一篇文章。
2.  点击"开始打字"。
3.  在打字页面阅读上方英文原文，并使用电脑实体键盘输入。
4.  页面提供虚拟键盘及手指提示，帮助熟悉键位；实际输入请使用实体键盘。
5.  完成后点击"提交并查看结果"。

系统会记录本次练习的打字速度（WPM）、准确率、差异数和练习时间，并在统计页面显示相关汇总。

建议练习时尽量完整输入文章。若输入内容与原文差异较大，准确率会相应降低。

## 七、书架与词书管理

书架用于查看当前词书、创建和导入自定义词书，以及管理数据备份。

### 导入自定义词书

1.  准备 CSV 或 TXT 文件。

2.  推荐每行使用以下格式：

    ``` text
    apple | /ˈæpəl/ | n. 苹果；苹果树
    abandon | /əˈbændən/ | v. 放弃；抛弃
    ```

3.  进入"书架"，填写词书名称并选择文件。

4.  点击"创建并导入词书"。

5.  等待导入完成，并确认词书已出现在书架中。

词库页面也提供文本导入区域，可直接粘贴单词列表。建议统一使用 UTF-8
编码，并在导入前检查分隔符和释义内容。

切换词书前后，建议确认页面显示的当前词书名称，避免误以为不同词书的学习进度相同。

## 八、词库与收藏

### 词库

-   可按英文单词或中文释义搜索。
-   可浏览单词、音标、中文释义和掌握状态。
-   点击"详细"查看词条扩展信息。
-   可展开导入区域，粘贴自定义词表。

### 收藏

-   在学习页面点击星标收藏单词。
-   再次点击星标可取消收藏。
-   进入"收藏"页面查看已收藏的单词。
-   收藏数量会显示在顶部导航附近。

收藏的单词也会参与作文训练薄弱词汇整理。

## 九、统计

进入"统计"页面可查看学习相关数据，例如累计完成词数、历史自评很熟率、已进入复习的词等。

作文打字成绩区域会显示已记录的练习次数、平均
WPM、平均准确率、累计差异数及最近练习记录。

统计数据来自当前浏览器保存的学习和练习记录。刚开始使用时，部分数据为 0
属于正常情况。

## 十、AI API 配置

作文训练支持用户自行配置 **OpenAI 兼容 Chat Completions
接口**。不同服务商的兼容程度可能不同，具体以服务商文档为准。

### 配置步骤

1.  进入"作文训练"。

2.  展开"AI API 设置"。

3.  填写以下内容：

    | 配置项 | 说明 | 示例 |
    | --- | --- | --- |
    | API Base URL | 服务商提供的 API 基础地址 | `https://api.openai.com/v1` |
    | API Key | 服务商提供的密钥 | 使用自己的密钥 |
    | 模型名称 | 服务商支持的模型 ID | `gpt-4o-mini` |

4.  点击"测试连接"检查配置。

5.  测试通过后点击"保存 API 设置"。

6.  返回作文训练区域，选择难度和目标词，点击"生成作文"。

程序会根据 Base URL 补全 Chat Completions
路径。请按服务商要求填写基础地址，不要随意添加或遗漏路径。

### API 使用注意事项

-   API 服务商必须支持 Chat Completions 请求格式及页面所需的返回结构。
-   浏览器直接请求第三方 API
    时，服务商必须允许当前网站来源跨域访问（CORS）。
-   API 调用可能产生费用或消耗套餐额度，请查看服务商的价格和用量规则。
-   API Key 会保存在当前浏览器本地，**不会写入项目文件，也不会包含在
    JSON 数据备份中**。
-   不要在公用电脑保存 API Key；使用完毕后可在设置中清除或替换密钥。
-   不要把 API Key、个人数据备份或包含密钥的截图提交到公开 GitHub 仓库。

如果接口不支持浏览器跨域访问，或不希望浏览器直接持有密钥，可以改用项目提供的
Cloudflare Worker 方案，具体参阅
[`docs/AI-WORKER-SETUP.md`](docs/AI-WORKER-SETUP.md)。

## 十一、数据备份与恢复

### 导出备份

1.  进入"书架"页面。
2.  找到"本地数据安全"区域。
3.  点击"导出全部数据 JSON"。
4.  将下载的 JSON 文件保存在安全位置。

备份包含项目保存的学习记录、词书、收藏、作文文章等本地数据；AI API
设置中的密钥不会被导出。

### 恢复备份

1.  进入"书架"页面。
2.  点击"恢复 JSON 备份"并选择此前导出的 JSON 文件。
3.  阅读覆盖提示，确认后执行恢复。
4.  页面会重新载入以读取恢复后的数据。

恢复会覆盖备份文件中同名的数据键。恢复前务必先导出当前数据，以免覆盖后无法找回较新的记录。

## 十二、数据保存与隐私

-   学习记录、收藏、词书、文章历史和练习成绩主要保存在当前浏览器本地。
-   项目使用 localStorage，并通过启动桥接同步镜像到 IndexedDB；不支持
    IndexedDB 时会回退到 localStorage。
-   数据按浏览器和设备隔离。GitHub Pages
    只负责托管网页，不会自动把个人学习数据同步到 GitHub。
-   更换浏览器、设备、使用无痕窗口或清除网站数据，都可能导致本地数据无法继续使用。换设备前请先导出
    JSON 备份。
-   不要把个人 JSON 备份上传到公开仓库。
-   AI 请求会将本次作文生成所需的提示内容和目标词发送给你配置的 API
    服务商；请阅读该服务商的隐私政策。

## 十三、常见问题

### 1. 刷新网页后学习记录不见了

先确认是否使用了相同浏览器、相同设备和相同网站地址，是否开启无痕模式，是否清理过浏览器站点数据。若有
JSON 备份，可在书架页面尝试恢复。

### 2. AI 生成作文失败

按顺序检查：

1.  API Base URL、API Key、模型名称是否填写正确。
2.  API Key 是否有效、是否有可用额度。
3.  模型是否支持 Chat Completions。
4.  服务商是否允许当前网站跨域请求（CORS）。
5.  查看页面显示的错误信息，并对照服务商文档检查。

### 3. 测试连接成功，但生成文章失败

测试连接不一定代表模型完全支持作文生成所需的格式。可尝试服务商推荐的兼容模型，检查模型是否支持
JSON 输出；如果服务商不支持 JSON
模式，程序会尝试普通文本请求，但模型返回格式仍可能影响解析。

### 4. 文章历史无法显示或滚动

建议使用最新版 Edge 或 Chrome，按 `Ctrl + F5`
强制刷新。如果仍有问题，请记录浏览器版本、页面地址和错误截图。

### 5. 删除历史文章后能否恢复？

页面没有撤销功能。若删除前导出过 JSON 备份，可以通过"书架 → 恢复 JSON
备份"恢复备份中的文章数据。恢复操作会覆盖备份中同名数据键，请先备份当前数据。

### 6. GitHub Pages 更新后仍显示旧页面

等待 GitHub Pages 部署完成，然后在浏览器按 `Ctrl + F5`
强制刷新。也可以稍后重新打开网站，检查是否已加载最新版本。
